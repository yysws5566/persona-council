# persona-council · 名人议会

> 单个AI给的是「平均答案」——把一个问题交给158个蒸馏人格竞价、立论、投票，才能看到被平均数抹掉的东西。

## 案例标题（SkillHub用）

名人议会——一个问题158个人格抢麦：双轴竞价+TOP10立论+新颖嘉宾席，输出HTML圆桌决策报告

## 简介

名人议会·多角度决策机制。聚合约160个蒸馏人设（投资大师、思想家、科学家、商业战略家、军事家、艺术家、方法论代言人、民生实务派、当代决策与方法论者），四阶段机制——双轴竞价（专业度×0.7+公众影响力×0.3，<60出局；另选新颖TOP3嘉宾席）→TOP10立论（论点查重联署，保十个不同角度）→专业度加权三维投票（洞察/可行/风险）→议长综合（共识/分歧/场外视角/条件建议/少数派报告）；方法型问题（怎么做X）自动追加落地转化——72小时清单+90天路线图+12-36月阶段路线+最低资源+止损线+周复盘，输出HTML圆桌报告。

## 适合人群

面临重大决策拿不定主意的人（职业/投资/创业/关系）；想对一个问题做压力测试的人；内容创作者、分析师——需要「不同段位的人怎么看这件事」的多视角素材。

## 能解决的问题

- 问AI「我该不该辞职」，得到一篇四平八稳的正确废话
- 身边全是同类人，决策盲区没人指出
- 方案只见过一种思路，不知道其他流派会怎么拆
- 少数派声音在讨论中一开始就被淹没

## 使用步骤

1. 抛出问题（越具体越好：处境+约束+目标）
2. 议会自动跑四阶段：双轴竞价选人→TOP10各立论（是什么/利弊/下一步/信心度）→评审团加权投票→议长综合
3. 看报告：共识区（≥7/10同意）、分歧区（各派最强一句）、场外视角（嘉宾破圈补丁）、条件式结论（if-then对号入座）、行动清单P0-P2
4. **问的是「怎么做X」时，报告自动追加落地方案**：72小时启动清单、90天路线图（带量化验收标准）、12-36月阶段路线、最低资源配置、止损线、每周复盘3问——每条动作带「今天能做・验收标准・花多少钱」三要素
5. 涉钱/健康/法律问题自动挂免责声明

## 机制亮点

- **双轴竞价**：专业度×0.7+公众影响力×0.3——冷门强手靠专业度入场，热门水货靠专业度出局
- **论点查重联署**：候选人核心论点与已入席者重合≥70%时合并为「+N人联署」，席位顺延给不同论点者——TOP10保证十个角度
- **🎭 新颖TOP3嘉宾席**：TOP10之外新颖度最高的3位只发≤150字「场外视角」，TOP10全员当评委表态采纳/保留/驳回——嘉宾的价值不在赢票，在把场外的话带进来
- **🛠️ 落地转化（v1.3）**：方法型问题强制把共识翻译成可执行方案，禁止「提升认知」「拥抱变化」类无动作建议，每个动作溯源到某席主张
- **v1.1 人设换血**：新增I团·当代决策与方法论18席（奥特曼/黄仁勋/安妮·杜克/俞军/曾鸣/特劳特等），远古哲人退冷席（问题涉及时特邀入场）

```

四阶段执行：双轴竞价（专业度×0.7+影响力×0.3，<60出局，另选新颖嘉宾3席）→TOP10立论（论点查重联署，每人「是什么/利/弊/下一步/信心度」，人设语气保真）→评审团加权三维投票（洞察/可行/风险，每票附理由）→议长综合（共识/分歧/场外视角采纳区/条件式结论/行动清单P0-P2）。
这是方法型问题，请追加落地方案：72小时启动清单（今天/明天/后天各一条）+90天路线图（月度里程碑+量化验收标准+不达标对策）+12-36月阶段路线+最低资源配置（0元版/必要版）+止损线+每周复盘3问，每条动作带「今天能做・验收标准・花多少钱」三要素并溯源到具体席位主张。
输出HTML圆桌报告（暖橙×墨蓝，含嘉宾席、少数派报告与全会总结），涉钱问题挂免责声明。
```
